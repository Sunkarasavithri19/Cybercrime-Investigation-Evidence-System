# Cybercrime Investigation & Evidence Management System — Streamlit

A Streamlit implementation of the landing page and interactive academic prototype.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

Open the local Streamlit URL shown in the terminal.
